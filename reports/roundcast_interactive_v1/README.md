# ROUNDCAST · 三案例交互预览

已完成 T01–T11（2026-09-06）。网页支持三个案例 × 两个时点 × 两种算法的 12 项真实推理，无选择链接时默认打开案例 A／购买结束／XGBoost。
可单独运行当前组合，也可“运行全部对比”：对当前案例依次运行四条模型。
这是连接真实冻结模型的本地网页，不是旧静态样板，也不是直播比赛。

比赛观众、比赛分析与技术分析三个视图已联动。技术页区分整个测试集的正式指标和当前回合的运行记录；页面下方保留 **Codex 回合对话**。

先看 [六页图文演示 PDF](roundcast-v1-demo-guide.pdf) 或 [三个案例逐步操作指南](demo_guide.md)。三页 1440/1280 完整截图、启动/关闭和录屏讲解顺序均已整理，最新 [T11 交付验收](t11_verification.md) 已通过。

## 使用 Codex 对话

1. 正常打开本机 Codex 并保持登录，然后从普通 PowerShell 启动本地服务。
2. 页面点“运行模型”，向下滚动到“和 Codex 聊聊这个回合”。
3. 输入问题或点击快捷问题，确认附带的案例和预测标识，点“发送给 Codex”。
4. 回复期间仍可运行模型；旧回答保留其提问时的预测标识，不冒充新的预测。
5. “停止回复”停止本次生成；“清空对话”清除本页记录。刷新不恢复记录。

该对话使用本机 Codex CLI 的已有登录，独立于桌面的每日主任务，不会同步其聊天历史。只附当前选中组合的成功预测，不自动附其他三项；切换案例或时点会重置发送的追问历史，可见旧记录保留原标签。
仅在点击发送时，问题、当前快照、本次成功预测及最近最多六轮对话发送到 Codex；
隐藏赛果、参考概率、模型文件和登录凭据不作为消息上传。会使用当前 Codex 账户额度。
本地推理无需外网；Codex 回复需要联网。未登录/不可用时显示明确状态，不使用模拟答案。
身份检查只证明 CLI 登录可用，不代表网络已连通。回复超时上限为 150 秒。
若提示登录不可确认，请在普通终端检查 `codex login status`，必要时自行登录后重启服务；
无需复制 `auth.json`，也不要把凭据放入代码或 GitHub。

对话以只读解释模式运行：不修改仓库、不训练模型、不代替页面运行其他组合。
没有计算过的归因、模型排名、玩家位置和事件不能当成已有结果。
采用临时工作目录和临时 Codex 会话；本页记录在内存中保留，清空不等于删除账户服务端记录。
详见 [对话验收](chat_verification.md) / [真实回复截图](chat-live-desktop.png)。

若服务已关闭，在 PowerShell 中运行：

```powershell
Set-Location 'C:\Users\admin\Documents\Codex\2026-07-06\th\work\csdemo_round_prediction'
& 'C:\Users\admin\11\envs\game\python.exe' -m src.csdemo.roundcast_server --host 127.0.0.1 --port 8765
```

## 演示流程

1. 使用不带选择片段的入口打开页面，初始为案例 A／购买结束／XGBoost，胜率为空、赛果隐藏。
2. 点击“运行当前组合”。CT 显示 **62.92%**，T 显示 **37.08%**；这是本次真实推理的显示舍入值。
3. 查看装备/现金对比和本次来源记录。展开来源可查看回合身份与完整哈希。
4. 点击“查看实际结果”：显示 CT 获胜。标签与模型输入独立。
5. 再次运行会重新调用模型并生成新请求标识。运行中或失败不保留旧成功概率。
6. 服务停止后，再次运行/读取赛果会报连接不可用；重新启动后可点“重新连接”。页面不在后台持续监测服务。
7. 点击“运行全部对比”，四行分别显示状态、CT/T 胜率及请求标识。失败项为“—”，点击该行“重试”只重跑这一项。
8. 点击时间轴节点或下拉框切换时点/算法；同一案例已经成功运行的对应结果可立即查看，不自动新推理。模型差只比较同一时点，单位为百分点。
9. 切换 B／C 后，旧预测、对比和赛果清空。首杀后会显示截止该时点的首杀阵营、时间、武器和爆头信息；购买结束视图不显示这些字段。
10. 点击顶部“比赛分析”，查看四个离散胜率点、同算法两时点变化、购买结束经济差和只读输入表。未运行/失败项不画点，两时点未同时成功时变化显示“—”。
11. 切回“比赛观众”或使用前进/后退，同一案例已运行结果保持一致；切案例仍清空。刷新仅恢复地址中的视图和选择，结果、揭示状态与聊天记录不恢复，也不自动运行。
12. 窄屏的点图和宽表可在各自区域内横向滚动；输入表可纵向滚动查看全部 27/31 项。
13. 点击“技术分析”：左侧为所选模型的五项正式指标，购买结束 4,172、首杀后 4,170 个测试回合，切换案例不改变指标。右侧为当前组合的实际运行记录。
14. 只有主动查看赛果并有当前成功预测时，右侧才显示本次预测正确/错误。未运行或失败不评判；单个案例对错不代表整体模型优劣。
15. 指标读取独立于推理；缺失、哈希不符或接口失败显示不可用，可点“重新读取正式指标”。不会回退为零，也不从三个案例算整体指标。
16. “重新连接”会先清除旧的模型就绪列表；完成前不能改案例/时点/算法，但仍可切换三个视图。响应缺少必要运行记录时显示错误，不把不完整结果渲染为成功。

处理耗时包含本次文件核验、模型加载和推理，不是单独的模型运算速度。
`uncalibrated` 表示当前使用恒等校准，不代表做了非恒等校准。
