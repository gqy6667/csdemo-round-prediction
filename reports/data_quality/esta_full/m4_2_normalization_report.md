# M4.2 inventory 规范化验收报告

完成日期：2026-08-16

## 实施规则

1. `weapon_bucket` 按单个存活玩家生成特征：同名武器只计一次，每名玩家最多贡献 1 把普通步枪。
2. 队伍手雷数不再直接信任 `side.totalUtility`，改为从存活玩家 inventory 重算，每名玩家最多贡献 4 颗。
3. 最接近 `freezeTimeEndTick` 的帧必须为 5v5，否则该回合及其击杀记录不进入标准表。
4. 原始 ESTA `.json.xz` 保持只读，规范化只发生在项目生成的中间表中。

## 测试结果

新增 3 个 M4.2 回归测试，分别覆盖：

- 同一玩家出现重复 `AK-47` 和多把不同主武器。
- 同一玩家出现 5 条手雷 inventory。
- 非 5v5 冻结结束快照及其击杀一起排除。

完整测试结果：15 个测试全部通过；`compileall` 通过。
