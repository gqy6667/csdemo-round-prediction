# M6 开局前特征字典

## 快照定义

每个样本取 `freezeTimeEndTick` 最近的一帧，即购买完毕、交火前。标签
`ct_win` 表示本回合最终是否由 CT 获胜。所有下列特征都必须在该帧已经可知，
不能使用首杀、伤害、下包或回合结束后的信息。

`*_diff_ct` 一律定义为 `CT 数值 - T 数值`。正数代表 CT 更多，负数代表 T 更多。

## 保留在中间表但不送入模型

| 特征 | 保留原因 | 不用于开局模型的原因 |
|---|---|---|
| `ct_alive` | 质量门禁和首杀后人数计算 | 合格开局样本恒为 5 |
| `t_alive` | 质量门禁和首杀后人数计算 | 合格开局样本恒为 5 |
| `alive_diff_ct` | 一致的派生字段 | 合格开局样本恒为 0 |

`series_id`、`game_id`、`round_id` 只用于关联和按系列赛切分，绝不能作为预测特征。
`split` 只标识训练/验证/测试集合，`ct_win` 是标签，也都不会进入模型。

## M6 调整原则

1. 先修复缺失、恒定或错误解析的字段，再讨论模型参数。
2. 新特征只能由购买结束帧及更早信息产生。
3. 每次新增或删除一组特征，都在固定 70/20/10 切分上比较验证集和测试集 AUC。
4. 测试集只用于阶段验收；日常选择方案主要看验证集，避免反复迎合测试集。
