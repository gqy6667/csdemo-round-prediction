# 开局前胜率模型指标说明

## 1. 模型在预测什么

预测时点已经正式定义为：

> 玩家购买完毕、冻结时间结束、双方正式交火之前。

模型输出 CT 获胜概率。例如：

```text
CT 获胜概率 = 0.70
T 获胜概率  = 0.30
```

真实结果使用 `ct_win` 表示：

- `ct_win = 1`：CT 赢得回合。
- `ct_win = 0`：T 赢得回合。

## 2. Accuracy：预测对了多少

Accuracy 中文通常叫准确率。

```text
Accuracy = 预测正确的回合数 / 全部回合数
```

模型默认以 0.5 为界：

- CT 概率 >= 0.5，预测 CT 赢。
- CT 概率 < 0.5，预测 T 赢。

当前完整基线：

```text
简单基线 Accuracy = 0.5244
XGBoost Accuracy  = 0.6512
阶段目标          = 0.6600
```

`0.6512` 表示约 65.12% 的测试回合胜负方向判断正确。Accuracy 容易理解，但它只检查最终方向，不关心 51% 和 99% 的区别，因此不能单独使用。

## 3. AUC：排序能力

AUC 衡量模型能否把真正由 CT 获胜的回合排在真正由 T 获胜的回合前面。

直观理解：随机抽一个 CT 获胜回合和一个 T 获胜回合，模型给 CT 获胜回合更高概率的机会。

```text
AUC = 0.50   接近随机排序
AUC = 1.00   完美排序
```

当前完整基线：

```text
简单基线 AUC = 0.5000
XGBoost AUC  = 0.7209
最低门槛     = 0.7000
阶段目标     = 0.7300
```

当前模型已经超过最低门槛，距离阶段目标约 0.0091。AUC 不直接说明概率是否准确，例如它不能保证模型说的 70% 真的会赢约 70%。

## 4. Log Loss：概率错得有多严重

Log Loss 中文常叫对数损失，越低越好。它会特别惩罚“非常自信但预测错误”的情况。

例如真实结果是 CT 获胜：

- 模型预测 CT 55%，虽然不够自信，但错误代价较小。
- 模型预测 CT 1%，非常自信地判断错了，错误代价很大。

当前完整基线：

```text
简单基线 Log Loss = 0.6926
XGBoost Log Loss  = 0.5941
最低门槛          = 0.6100
阶段目标          = 0.5800
```

当前已经达到最低门槛，距离阶段目标还需下降约 0.0141。对于胜率模型，Log Loss 通常比 Accuracy 更重要，因为最终需要的是可信概率，而不只是 CT/T 两个类别。

## 5. Brier Score：概率与结果的平方误差

Brier Score 是预测概率与真实结果之间的平均平方误差，越低越好。

```text
Brier = 平均值((预测的 CT 概率 - ct_win)²)
```

示例：CT 实际获胜，即 `ct_win=1`。

- 预测 0.9，平方误差是 `(0.9-1)² = 0.01`。
- 预测 0.2，平方误差是 `(0.2-1)² = 0.64`。

当前完整基线：

```text
简单基线 Brier = 0.2497
XGBoost Brier  = 0.2062
最低门槛       = 0.2100
阶段目标       = 0.1950
```

当前达到最低门槛，还没有达到阶段目标。

## 6. ECE：70% 是否真的接近 70%

ECE 是 Expected Calibration Error，中文可理解为期望校准误差，越低越好。

计算时把预测概率分桶，例如：

```text
预测在 60%-70% 的回合放进一组
比较这组平均预测概率与真实 CT 胜率
```

如果一组平均预测为 65%，真实 CT 胜率也约 65%，说明这一组校准较好。

当前临时结果：

```text
ECE（10 桶） = 0.0216
最低门槛     = 0.0400
阶段目标     = 0.0300
```

这个数值初步达到目标，但目前只是一次诊断计算。还需要保存正式校准报告和校准曲线，才能把该模块标记为完成。

## 7. Train-Val AUC 差：检查过拟合

训练集指标明显好于验证集，通常表示模型记住了训练数据中的规律，但对新比赛泛化不足。

当前结果：

```text
训练集 AUC       = 0.7718
验证集 AUC       = 0.7144
Train-Val AUC 差 = 0.0574
最低要求         <= 0.0500
阶段目标         <= 0.0300
```

当前尚未达到最低要求。后续将通过 early stopping、限制树复杂度、正则化和特征检查降低差距。

## 8. 指标查看顺序

本项目建议按以下顺序阅读：

1. 先看数据质量和测试集是否真正独立。
2. 看 AUC，判断模型有没有排序能力。
3. 看 Log Loss 和 Brier，判断概率误差。
4. 看 ECE 和校准曲线，判断概率是否可信。
5. 看 Accuracy，得到最直观的胜负判断比例。
6. 比较训练集与验证集差距，检查过拟合。
7. 查看分地图、LAN/online 指标，检查模型是否只在部分数据上有效。

任何单个指标都不能独立证明模型优秀。项目最终要同时满足数据正确、泛化稳定、概率可信和可以解释。
